# โรงเรียน AI สำหรับวิศวกรโยธา — เริ่มอ่านที่นี่

> **สำหรับใคร:** มะขาม (วิศวกรโยธา) ที่ทำโปรเจกต์ทูน VLM อ่านแบบก่อสร้างมาหลายรอบแล้ว (t01 ถึง t05) แต่ยังไม่เข้าใจว่า "ข้างใน" มันทำงานอย่างไร
> **เป้าหมาย:** อ่านจบแล้วอธิบายได้เองว่า AI เรียนรู้อย่างไร, LLM/VLM เกิดจากอะไร, fine-tuning ทำอะไรกับโมเดลจริง ๆ, ทำไมต้องมี OpenCV คู่กับ VLM, และวัดผลอย่างไรไม่ให้หลอกตัวเอง จนถึงระดับที่อ่าน paper และตั้งคำถามวิจัยเองได้
> **สถานะ:** ฉบับร่างสำหรับ review ร่วมกัน (2026-09-08) ก่อนแปลงเป็น HTML แบบ interactive

## ความต่างจาก `workmen's_diary/สอนมะขาม_รวม.md`

ไดอารี่สอนมะขามอธิบาย "วันนี้เกิดอะไรขึ้นและทำไม" ตามเหตุการณ์จริง (OOM, GGUF, SSH, บั๊ก collator)
หลักสูตรนี้อธิบาย "หลักการที่อยู่เบื้องหลังเหตุการณ์เหล่านั้น" เรียงตามลำดับความรู้ ไม่ใช่ตามวันที่
ทุกบทจะชี้กลับไปที่เหตุการณ์ในไดอารี่และไฟล์ในรีโป เพื่อให้ทฤษฎีกับสิ่งที่เจอจริงเชื่อมกัน

## วิธีใช้หลักสูตรนี้

1. อ่านตามลำดับ บทหลังอ้างแนวคิดจากบทก่อนเสมอ
2. ทุกหัวข้อย่อยมีบล็อก 🎨 **ภาพที่จะวาดใน HTML** อธิบายว่า visualization แบบ interactive ควรเป็นอย่างไร ตอน review ให้ดูว่าภาพไหนช่วยจริง ภาพไหนไม่จำเป็น เพื่อให้ขั้น HTML ทำเฉพาะที่คุ้ม
3. โค้ด Python ในบทรันได้จริงบนเครื่องธรรมดา (numpy / torch CPU / cv2) ลองรันแล้วดูตัวเลขเอง
4. ท้ายทุกบทมี "ที่มาและอ่านต่อ" อ้าง paper ต้นฉบับและเอกสารทางการ ถ้าจะไปต่อระดับวิจัย ให้อ่านต้นฉบับ ไม่ใช่แค่บทสรุปนี้
5. ส่วน "เชื่อมกับงานของเรา" ในทุกบทคือจุดที่ทฤษฎีอธิบายบั๊กที่เราเคยเจอ ตรงนี้คือหัวใจ
