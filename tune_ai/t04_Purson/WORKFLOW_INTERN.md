## ⛔ กฎเหล็กก่อนแตะอะไร (อ่าน 1 นาที ประหยัดหายนะ 1 คืน)

1. **ห้ามแก้/ลบไฟล์ใต้ `rawjson_ยังไม่ได้แก้ไขโดนคน/` เด็ดขาด** — ground truth
   ต้องมีคำสั่งมะขามเท่านั้น (กติกาเต็ม: `No_touch_box/docs/rule_of_tune.md`)
2. งานเช่า GPU: **การ์ดถูกก่อนเสมอ** ทดสอบจบ 1 หน้าก่อนขยับการ์ดแรง ·
   **venv แยกเสมอ** ห้าม pip install ลง env ที่มีงานอื่นรันอยู่ ·
   **ก่อน destroy เครื่อง ดึงผลลัพธ์กลับมาก่อนทุกครั้ง** (destroy = หายถาวร ไม่ใช่ stop)
3. ส่งงาน JSON ทุกครั้งต้องผ่าน `python tools/check_format.py <โฟลเดอร์บ้าน>` exit 0 ก่อน
   ห้ามตรวจด้วยตาแทน

```

  ↓ Pass 1.5  cv_scan.py ตา CV นับ element + ทำ hint
  ↓ Pass 2/2.4 Qwen อ่านแบบ (GPU — ตาม RUNBOOK, แขน 2 vs 2.4a)

  → check_format.py ก่อนส่งทุกครั้ง
```

## ข้อ 1 — Pass 0: คัดหน้า (VLM + OCR ช่วย, ยังไม่มีสคริปต์ยิงจริง)

**สถานะจริง: ไม่มี runner** — ตัวคัดหน้ายังต้องเป็น **VLM (Qwen) เท่านั้น**, prompt อยู่
`tune_ai/t04_Purson/pass0/prompt.md` รูปแบบผลลัพธ์อยู่ `output_example.json` ข้างกัน
**ทดลองเปลี่ยนไปใช้ OCR ล้วนแล้ว (2026-08-29) — ไม่ไหว** OCR อ่านตัวหนังสือในกรอบชื่อแบบเองก็พัง
(easyocr 0/4 หน้า) และต่อให้อ่านออกหมด ก็ยังตอบ `views[]` (หน้านี้กี่รูป ตัดตรงไหน
`also_gridline` ไหม) ไม่ได้เลย เพราะนั่นเป็นการตัดสิน layout ไม่ใช่ text — VLM ยังจำเป็นเสมอ

**สิ่งใหม่ (2026-08-29 คืน): OCR ช่วยเป็นคำใบ้เสริมได้แล้ว** หลังแก้ crop/engine จนแม่นขึ้นมาก
(PaddleOCR PP-OCRv5 lang=th, local ไม่ต้อง API key — วัดจริง 27 หน้า: sheet_code ตรง 24/26)
รันก่อนเรียก VLM:

```bash
python tools/titleblock_ocr.py --dir image/<บ้าน>/
```

จะได้ `<บ้าน>_หน้าNN_titleblock_hint.txt` ข้างรูปที่ OCR อ่านออก (ไม่ใช่ทุกหน้า — บางหน้าไม่มี
สิ่งที่อ่านได้จริงจะไม่มีไฟล์นี้เกิด ปกติ) ถ้ามีไฟล์นี้ ให้แปะต่อท้าย prompt เป็น
`{{TITLEBLOCK_OCR}}` ตามที่ `pass0_classify/prompt.md` อธิบายไว้ — **ช่วยแค่ sheet_code/
sheet_name เท่านั้น ไม่ช่วย views[]** อย่าคาดหวังเกินนี้

วิธีทำวันนี้: (ไม่บังคับ) รัน `titleblock_ocr.py` ก่อนก็ได้ → เอา prompt + รูปทีละหน้า
(+ hint ถ้ามี) ป้อนโมเดล (หรือให้ Claude ทำ) → รวมผลทุกหน้าเป็น `pass0_<บ้าน>.json`
ตามรูปแบบตัวอย่าง

เช็คว่าผ่าน: ทุกหน้ามี entry ครบ ไม่มีหน้าตกหล่น (นับจำนวน entry = จำนวน png) —
**นี่คือด่านอันตรายสุดของสายพาน** หน้าที่คัดผิดจะหายไปทั้งสาย (เคยเกิดจริง:
โครงหลังคาหาย 8 ใน 11 หลัง)

## ข้อ 3 — Pass 1.5: ตา CV (CPU)

```bash
python tools/cv_scan.py --manifest work/<บ้าน>
```

ได้ 3 ไฟล์ต่อหน้า (ใน `cv/` ข้าง images/): `_cv.json` (พิกัด+เลขกำกับ) ·
`_marked.png` (ภาพมาร์คเลข — **ไว้ให้คนดู ไม่ป้อนโมเดล**) · `_hint.txt` (ข้อความ hint)

**เช็คด้วยตาเสมอ (บั๊ก 2 คลาสที่ self-check มองไม่เห็น):** เปิด `_marked.png` 4-5 รูป —
(ก) เลขกำกับไม่ทับกันเอง (ข) ป้ายขาวไม่บังมาร์คจริงบนแบบ (เช่นเลข "1" ของ F1)
เจอเคสใหม่ให้จดหน้านั้นส่งทีม อย่าแก้โค้ดเอง

หน้าที่ CV นับได้ 0 ทั้งที่มีของจริง = คลัง template ยังไม่รู้จักซีรีส์นั้น (ปกติ ไม่ใช่บั๊ก) —
จดไว้ บ้านนั้นแขน 2.4 จะกลายเป็นแขน 2 เองอัตโนมัติ

ก่อนเริ่มงานทุกรอบ รัน self-check เครื่องมือได้ด้วย:

```bash
python tools/cv_scan.py --demo        # ต้องจบ "OK — self-check ผ่านทุกข้อ"
python tools/merge_guard.py           # ต้องจบ OK
```

## ข้อ 5 — Pass 2.5: self-harvest (CPU)

```bash
python tools/cv_scan.py --manifest work/<บ้าน> --pass25
```

ได้ชุดไฟล์ลงท้าย `25` (`_cv25.json` / `_marked25.png` / `_hint25.txt`) — เป็น**บัญชีตั้งต้น
ของ pass 3** อย่าสับสนกับชุดเปล่าของข้อ 3: **ชุดเปล่า = ให้แขน 2.4 · ชุด 25 = ให้ pass 3**
(กับดักจริง เจอมาแล้ว — แขน 2.4 อ่านแต่ชุดเปล่า)

เช็คว่าผ่าน: `self_harvest_added` ใน `_cv25.json` ≥ 0 และจำนวน element ไม่ลดจากชุดเปล่า
(harvest เพิ่มได้อย่างเดียว ห้ามทำของหาย — self-check ยืนยันกฎนี้อยู่แล้ว)
