## ข้อ 1 — Pass 1.5: CV สแกนหน้า plan ของ 5 บ้าน val (CPU, ไม่ใช้ GPU)

**Claude รันไว้ให้แล้วคืน 2026-08-28** → sidecar อยู่ `tune_ai/t03/data_before_tune/cv_val/`
(25 หน้า plan จาก val.jsonl ของบ้าน 01–05, รวม `--pass25` self-harvest ด้วย)

ถ้าต้องรันใหม่ (เช่น เติมคลัง template แล้ว):

```bash
python - <<'PY'
import json, sys
from pathlib import Path
sys.path.insert(0,'tools')
from cv_scan import scan_paths, load_templates
HERE=Path('tune_ai/t03/data_before_tune'); OUT=HERE/'cv_val'; OUT.mkdir(exist_ok=True)
imgs={HERE/c['image'] for line in open(HERE/'val.jsonl',encoding='utf-8')
      for r in [json.loads(line)] if (r.get('subtask') or '').startswith('plan_')
      for c in r['messages'][0]['content'] if c['type']=='image'}
tpls=load_templates()
scan_paths(sorted(imgs), tpls, lambda i: OUT, pass25=False)  # ชุด pass 1.5 — แขน 2.4 ใช้
scan_paths(sorted(imgs), tpls, lambda i: OUT, pass25=True)   # ชุด pass 2.5 — pass 3 ใช้
PY
```

**กับดัก suffix (เจอจริง 2026-08-28):** ใน `cv_val/` มีไฟล์ **2 ชุด** และใช้คนละงาน —
ชุดเปล่า (`_cv.json`/`_hint.txt`/`_marked.png`) = ผล pass 1.5 → **`apply_arm()` ของแขน 2.4 อ่านชุดนี้เท่านั้น**;
ชุดลงท้าย 25 (`_cv25.json`/`_marked25.png`) = ผล self-harvest pass 2.5 → เก็บไว้เป็นบัญชีของ pass 3
ถ้าแขน 2.4 ขึ้น `hint_used: false` ทั้งที่ sidecar มี ให้เช็คก่อนเลยว่ามีไฟล์**ชุดเปล่า**จริงไหม

**เช็คด้วยตาก่อนไปต่อ (สำคัญ — บั๊ก 2 ตัวที่เคยเจอ ตาเท่านั้นที่เห็น):**
เปิด `cv_val/*_marked.png` สัก 4-5 รูป ดูว่า (ก) เลข #n ไม่ทับกันเอง (ข) ป้ายขาวไม่บังมาร์คจริง
บนแบบ (เช่นเลข "1" ของ F1) — เจอเคสใหม่ให้จดหน้านั้นไว้ อย่าเพิ่งแก้โค้ดกลางดึก

หน้าที่ CV หาไม่เจอเลย (คลัง template ยังไม่รู้จักซีรีส์นั้น) → แขน 2.4 ของหน้านั้นจะกลายเป็น
แขน 2 โดยพฤตินัติโดยอัตโนมัติ (`hint_used: false` ใน results) — ไม่ใช่บั๊ก บันทึกไว้เฉยๆ

## ข้อ 4 — อ่านผล ตัดสินด้วยเลข

ต่อ (บ้าน × subtask) เทียบ 3 แขนด้วย 4 ตัวจาก `score_ids()` ใน summary ของแต่ละโฟลเดอร์ผล:

| ตัว | 2.4 ชนะเมื่อ |
|---|---|
| `recall_printed` (ตัวหลัก) | สูงขึ้น |
| จำนวนหลอน (id ไม่มีใน GT) | **ไม่เพิ่ม** — recall ขึ้นแต่หลอนขึ้นด้วย = hint คือเชิญหลอน แพ้ |
| จำนวน element ที่ตอบ | เข้าใกล้ GT |
| `null` ซื่อสัตย์ | มีได้ ไม่ใช่แต้มลบ |

ผลที่เป็นไปได้ 3 ทาง → งานต่อ:
- **2.4b ชนะชัด** → คุ้มค่ามาร์คภาพ: แผนต่อไปคือใส่ภาพมาร์คเข้าชุดเทรน (`build_dataset_t03.py` มีภาพครบ วาดเองได้)
- **2.4a ≈ 2.4b** → ใช้ข้อความล้วน ถูกกว่ามากตอนเทรน
- **แขน 2 ชนะ** → โมเดล fine-tune แล้วมองข้าม hint (ข้อกังวลที่จดไว้ใน pass_design_v2.md) —
  จบแนวนี้ได้เลย เสียแค่ค่ายิง ไม่ต้องเสียดาย

ลงผลใน `pass_design_v2.md` § สถานะลงมือ + workmen's diary ตาม convention
