เข้าไปทีละหน้า ผ่าน 8 ด่าน ออกมาเป็น JSON ที่ Constistant ใช้คำนวณ BOQ/BBS ได้จริง

```
PDF 20-30 หน้า
   │
 Pass 0     Qwen คัดหน้า → subtask + views + where          ← เดิม ไม่แตะ
   │
 Pass 1     โค้ดตัดรูป + แยกโฟลเดอร์ (organize.py)           ← เดิม ไม่แตะ
   │

   │
 Pass 2.5   self-harvest — เอาที่เจอแล้วมาเป็น template ใหม่  ← ใหม่
```

## ทีละด่าน

### Pass 0 — คัดหน้า (Qwen, ไม่แตะ)
ดูทีละหน้า ตอบว่า: เลขแผ่น, ชื่อแบบ (จาก title block), เป็นงานอะไร, และ**ในหน้านี้มีกี่รูป
รูปละอยู่ตรงไหน** (บน/กลาง/ล่าง) — หนึ่งหน้ามี 2-3 รูปก็มี ต้องคัดครบ ไม่งั้นรูปหาย

ด่านนี้อันตรายสุด เพราะคัดผิด = หน้านั้นหลุดจากทั้งสายพาน (เคยเกิดจริง: แปลนโครงหลังคาโดนติดป้าย
ผิด 8 ใน 11 หลัง คานหลังคาหายหมด)

### Pass 1 — จัดของ (โค้ดล้วน ไม่ใช้ AI)
`organize.py` อ่านผล pass 0 แล้วตัดรูปจริงออกเป็นรูปละ 1 view แยกลงโฟลเดอร์ตามประเภท
ทำไมต้องตัดจริง: โควตาความละเอียดต่อรูปคงที่ ตัดครึ่งมา = ความชัดเจนต่อพื้นที่เพิ่มเป็นเท่าตัวฟรีๆ

### Pass 1.5 — ตา CV ตรวจของที่ตัดแล้ว 🆕
เฉพาะ 4 โฟลเดอร์ผังโครงสร้าง (ฐานราก/เสา/คาน/พื้น) — `tools/cv_scan.py` เอา template จริงไปถูหา
ทั้งภาพ (ไม่ใช่ AI เลย มั่วไม่เป็น) ได้ 3 อย่างต่อภาพ:
- บัญชี element เลขกำกับ **#n คงที่**
- ภาพมาร์คเลขทาบลงแบบ (เทคนิค Set-of-Mark, arXiv 2310.11441)
- ข้อความ hint สั้นๆ พร้อมกฎกันหลอน 4 ข้อ

### Pass 2 / 2.4 — Qwen อ่านแบบจริง (การทดลอง A/B/C)

| แขน | ภาพ | hint |
|---|---|---|
| **2** | เปล่า | ไม่มี ← ตัวคุม (พฤติกรรมวันนี้) |
| **2.4a** | เปล่า | มีข้อความ |
| **2.4b** | มาร์คเลข | มีข้อความ |

ยิงหน้าเดียวกัน 3 รอบต่างกันแค่ input วัดว่า hint ช่วยจริงหรือทำให้หลอนหนักขึ้น
— **ยังไม่เคยยิงจริง รอ GPU**

### Pass 2.5 — self-harvest 🆕
เอา element ที่เจอแล้ว (มั่นใจสูง) ไป crop เป็น template ใหม่ กวาดซ้ำแบบเข้ม (0.90) หาตัวที่คลัง
template กลางจับไม่ติด — **พิสูจน์แล้วด้วยตา 2 หลัง ได้ผลตรง GT เป๊ะ** ข้อจำกัด: กู้ได้แค่ชนิด
เดียวกับที่คลังจับติดแล้วเท่านั้น

### Pass 3 — ถอดระยะ/เหล็ก 🆕 (ยังไม่เคยรัน)
Qwen อ่านระยะ/เหล็กจากบัญชีที่ยืนยันแล้ว **กฎเหล็ก: ห้ามลบ element ที่ 2.5 เจอ** — บังคับด้วยโค้ด
(`tools/merge_guard.py`) ไม่ใช่แค่สั่งใน prompt เพราะโมเดลเชื่อไม่ได้ในเรื่องนี้ ตัวไหนหาย
ใส่กลับเป็น stub ติดธงให้คนดู

### Pass 4 — หน้ารอง (= pass 3 เดิม แค่เปลี่ยนเลข)
สถาปัตย์/ไฟฟ้า/สุขาภิบาล/ปก/สารบัญ — แกะเก็บคลังไว้ ยังไม่มีใครใช้ตอนนี้

## สรุปหัวใจ

ของเดิม (0, 1, 4) **ไม่แตะเลย** ของใหม่ทั้งหมด (1.5, 2.4, 2.5, 3) คือการเอา**ตาที่ไม่ใช้ AI**
มาคอยจับผิด/เสริม AI ทุกจุด — เขียนโค้ดครบแล้ว ทดสอบได้จริงบางส่วน เหลือแค่ยิงบน GPU จริงเพื่อดูว่า
hint ช่วยได้แค่ไหน
