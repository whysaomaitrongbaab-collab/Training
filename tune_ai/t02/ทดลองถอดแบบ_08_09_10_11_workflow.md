## Phase 2 — ทดสอบสั้นก่อนเสมอ (ห้ามข้าม — ด่านเดียวที่กันเสียเงินทั้งก้อนถ้าอะไรพัง)

```bash

    --houses 08 --limit 5
```

ดูให้ผ่านก่อนไปต่อ:
- `image processor: 5120 visual tokens/ภาพ` (ถ้าได้ ~205 = พัง หยุดทันที ดู bug 2 ใน t02_workflow.md)
- JSON valid บางส่วนพอ **ไม่ต้องเกือบ 100% เหมือนบ้าน train** — บ้านนี้ไม่เคยเห็นมาก่อน
- จดเวลาเฉลี่ย/หน้า จากตัวเลขสรุปท้าย log → คูณ 348 (หรือ 211 ถ้าตัดบ้าน 11) = เวลารวมจริง
  → คูณราคา/ชม. = ค่าเช่ารวมจริง
