## Phase 2 — ทดสอบสั้นก่อนเสมอ (ห้ามข้าม — เป็นด่านเดียวที่กันเสียเงินทั้งก้อนถ้าอะไรพัง)

```bash
huggingface-cli login          # พิมพ์ token ตรงบน SSH session ห้ามส่งผ่านแชท
python3 run_house_batch.py --images-root /workspace/tune/image --out-root /workspace/tune/ผล \
    --houses 01 --limit 5
```

ดูให้ผ่านก่อนไปต่อ:
- `image processor: 5120 visual tokens/ภาพ` (ถ้าได้ ~205 = พัง หยุดทันที ดู bug 2 ใน t02_workflow.md)
- 5 หน้าแรกได้ `OK` (JSON valid) ส่วนใหญ่ (บ้าน 01 = train set ควรได้เกือบ 100%)
- จดเวลาเฉลี่ย/หน้า จากตัวเลขสรุปท้าย log → คูณ 244 = เวลารวมจริง → คูณราคา/ชม. = ค่าเช่ารวมจริง
