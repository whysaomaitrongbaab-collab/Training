# ⭐ วิธีที่ง่ายที่สุด: ดับเบิลคลิกไฟล์เดียว

**ไม่ต้องเปิด terminal · ไม่ต้องพิมพ์คำสั่ง · ไม่ต้องจำอะไรเลย**

ดับเบิลคลิกไฟล์นี้:

```
D:\purson\GO.bat
```

จะขึ้นเมนูให้กดเลข:

```
  1  เปิดใช้งาน   (เช่าการ์ด + เปิดโมเดล + เปิดตัวรับงาน)
  2  เช็คสถานะ    (การ์ดยังเปิดอยู่ไหม โมเดลตอบไหม)
  3  คืนการ์ด     (จบงานแล้วต้องกดทุกครั้ง)
  4  ทดสอบโมเดล   (ยิง 1 ครั้ง ดูว่าตอบจริง)
  5  ต่อ tunnel ใหม่ (ถ้าหลุด)
  0  ออก
```

**วันงานจริงใช้แค่ 2 ปุ่ม: กด `1` ตอนเริ่ม · กด `3` ตอนจบ** — เมนูจัดการที่เหลือให้เอง
(รวมถึงเช็คการ์ดค้าง เปิดหน้าต่างรับงาน และทดสอบว่าโมเดลตอบจริง)

> เมนูจะเตือนเองถ้ากด `0` ออกทั้งที่การ์ดยังเปิดอยู่ (กันลืมคืน = กันเงินเดิน)

หัวข้อที่เหลือด้านล่างคือ **วิธีพิมพ์คำสั่งเอง** เก็บไว้เผื่อเมนูมีปัญหา หรืออยากรู้ว่ามันทำอะไรอยู่

## วันงานจริง

### ช่วงเช้า / ล่วงหน้า ~1 ชั่วโมงก่อนพรีเซนต์

**1. เปิด Terminal ที่ 1**

```
cd D:\purson
```

**2. เช็คก่อนว่ามีการ์ดค้างอยู่ไหม** (ถ้ามี `up` จะไม่ยอมทำงาน)

```
python presentation.py status
```

ถ้าเห็นว่ามี instance ค้าง ให้คืนก่อน:

```
python presentation.py down
```

**3. สั่งเช่าการ์ด + เปิดโมเดล**

```
python presentation.py up --yes --max-price 1.5
```

เลือกรุ่นโมเดลได้ด้วย `--model` (ค่าเริ่มต้นคือ `t03`):

| รุ่น | คำสั่ง | สถานะ |
|---|---|---|
| **destrier** | `--model destrier` | **รุ่นที่ใช้อยู่ตอนนี้** — soup 3 fold รอบ t05 · แก้ค่า decode แล้ว 31 ส.ค. |
| **t03** | `--model t03` | รุ่นเก่า เก็บไว้เทียบ |

> เมนู `GO.bat` จะถามให้เลือกรุ่นทุกครั้ง (Enter เฉยๆ = destrier)

ระบบจะทำให้อัตโนมัติ: หาการ์ดว่าง → เช่า → ลง dependency → อัปโหลดโมเดล → เปิดเซิร์ฟเวอร์ → ต่อ tunnel → รอจนพร้อม

**ใช้เวลารวม 20-45 นาที** (ส่วนใหญ่หมดไปกับโหลดโมเดล 70GB) — อย่าปิด terminal ระหว่างรอ

**4. เห็นข้อความนี้ = พร้อม**

```
พร้อมแล้ว — เปิดอีก terminal แล้วรัน: python worker.py
```

**5. ทดสอบเบื้องต้น** (แนะนำ)

```
python presentation.py smoke
```

ต้องเห็นว่าผ่าน — ถ้าไม่ผ่าน อย่าเพิ่งไปสาธิตสด ดูหัวข้อ "ถ้ามีปัญหา"

**6. เปิด Terminal ที่ 2 (แยกกัน) แล้วเริ่มรับงาน**

```
cd D:\purson
python worker.py
```

ปล่อยหน้าต่างนี้เปิดตลอดช่วงสาธิต · เห็นบรรทัด `purson worker เริ่ม — GPU: ...` = พร้อมรับงานจากเว็บแล้ว

> ตอนนี้มี **2 terminal เปิดค้าง (ห้ามปิด)** + การ์ดเช่า 1 เครื่อง = พร้อมสาธิต

2. อัปโหลดไฟล์ PDF แบบก่อสร้าง
3. กดปุ่ม **🤖 ถอดแบบด้วย Purson (AI ของเรา)**
4. ปุ่มจะเปลี่ยนเป็น "⏳ กำลังถอดแบบ..." และเห็นสถานะเป็นขั้นๆ:

✅ รอ worker รับงาน
✅ worker ดาวน์โหลดรูป
✅ จำแนกว่าแต่ละหน้าคือแบบอะไร

   หน้า 27 · แปลนคาน
   ความคืบหน้ารวม              33%
   ▓▓▓▓▓░░░░░░░░░░░
ผ่านไป 15 นาที · เหลืออีกประมาณ 17 นาที · อ่านได้แล้ว 42 ชิ้น

5. เสร็จแล้วเข้าหน้าติ๊กเลือกอัตโนมัติ — ติ๊กรายการที่ถูก แล้วกด **✅ ยืนยันนำเข้า**

> **สลับแท็บไปทำอย่างอื่นระหว่างรอได้** — พอเสร็จชื่อแท็บจะกะพริบ "✅ ถอดแบบเสร็จ" เตือนเอง

> 🚫 **ห้ามกดปุ่มถอดแบบซ้อนกัน 2 งาน** (คนละโปรเจกต์/คนละเบราว์เซอร์ก็ห้าม) — ดูข้อจำกัดข้อ 1

> ⏱ **~4-5 นาทีต่อหน้า** — บ้านเต็มหลัง (~38 งาน) ใช้เวลาราว 3 ชั่วโมง **ไม่เหมาะกดสดบนเวที** ควรโชว์สด 1-3 หน้า แล้วโชว์ผลเต็มที่เตรียมไว้ล่วงหน้าแยก

## ⚠️ ข้อจำกัดที่ต้องรู้

### 1. ยิงพร้อมกัน 2 งาน → เซิร์ฟเวอร์ค้างทั้งระบบ

ถ้ามี 2 คำขอเข้าโมเดลพร้อมกัน เซิร์ฟเวอร์จะค้างสนิทนานหลายชั่วโมง ไม่ตอบแม้แต่คำขอเช็คสถานะ

**วิธีป้องกัน:** ให้มีคนเดียวกดปุ่มทีละครั้ง **รอผลเสร็จก่อนกดครั้งถัดไปเสมอ**

> อาการนี้เกิดจากโมเดลวนซ้ำไม่จบแล้วบล็อกงานอื่น · **31 ส.ค. แก้ต้นเหตุการวนซ้ำไปแล้ว** (เลิกใช้ greedy decoding
> ตามที่ Qwen แนะนำ) อาการน่าจะดีขึ้นมาก แต่ **ยังไม่ได้ทดสอบยิงพร้อมกันซ้ำหลังแก้** — ยังห้ามไว้ก่อน

### 2. แปลนคานยังอ่านไม่แม่น

ผลวัดล่าสุด (31 ส.ค. บ้านไทยพอเพียง3 หน้า 26/27 — บ้านที่โมเดลไม่เคยเห็น):

| หน้า | ผล |
|---|---|
| **แปลนฐานราก** | อ่านถูก **ทุกตัว ทุกตำแหน่ง** (F4/F7/F8/F11 ครบ 12 ฐาน) |
| **แปลนคาน** | รู้จักชื่อคาน 89% แต่วางตำแหน่งผิดบางท่อน · พื้นสำเร็จรูปหายทั้งหมด |

**คำแนะนำวันสาธิต:** โชว์ **หน้าแปลนฐานราก / ตารางเหล็ก / รูปตัด** จะได้ผลน่าประทับใจและตรงความจริง
ถ้ามีคนถามเรื่องแปลนคาน พูดตรงๆ ได้เลยว่า *"ยังอยู่ระหว่างพัฒนา รุ่นต่อไปกำลังแก้จุดนี้"*

### 3. ความเร็ว ~4-5 นาทีต่อหน้า

บ้านเต็มหลัง (~38 งาน) ราว 3 ชั่วโมง — เตรียมผลล่วงหน้า หรือโชว์สดแค่ 1-3 หน้าเพื่อสาธิตกลไก

### 4. ราคาเช่าการ์ด

~$1.07-1.13/ชั่วโมง (RTX PRO 6000 96GB) — พรีเซนต์ 2-3 ชั่วโมงรวมเวลาโหลดโมเดล **ราว $3-4**
