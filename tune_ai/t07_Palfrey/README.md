## คำสั่งที่ใช้บ่อย (รันจากราก t07)
- สร้างชุดข้อมูล: `python สร้างชุดข้อมูล/build_t07.py` · ชุดไม่รวม siamplan: `python สร้างชุดข้อมูล/build_t07.py --exclude-source siamplan --root ชุดทางเลือก_ไม่มีsiamplan`
- ตรวจตัวล้าง: `python สร้างชุดข้อมูล/sanitize_labels.py --selftest`
- ทำ bundle: `python tools/make_bundle.py` → `D:\00mk\steel project\training\t07_bundle\`
- หา offer (อ่านอย่างเดียว): `python tools/offers_t07.py`

## กติกาการดูแลโฟลเดอร์
- ไฟล์ใหม่ต้องลงโฟลเดอร์ตามหน้าที่ข้างบน ไม่วางไว้ที่ราก
- ชื่อโฟลเดอร์ไม่มีเว้นวรรค (กันคำสั่ง shell พัง) ถ้าจะเปลี่ยนชื่ออีก ต้องแก้สคริปต์ที่อ้างและทำ bundle ใหม่
- อย่าแก้ไฟล์ใน `ข้อมูลเทรน/` หรือ `ข้อมูลก่อนล้าง/` ด้วยมือ ให้สร้างใหม่ด้วย `สร้างชุดข้อมูล/build_t07.py`
- อย่าแก้ไฟล์ prompt โดยไม่สร้างชุดข้อมูลและ bundle ใหม่ตาม
- ของเก่าให้ย้ายเข้า `ของเก่า/` ไม่ลบ · ชุดใหญ่ที่สร้างใหม่ได้ให้ใส่ .gitignore
