# pass_find_element — ใครหา element (สถานะ 21 พ.ย. 2569)

ล็อกและตรวจตำแหน่งบนภาพ: ใช้ logic วัดแล้ว (จุด 99.5% เทียบตัวควบคุม 16.8% · คาน 92.7% เทียบ 16.5%)
หา element จากภาพ: ตั้งใจให้โมเดล t07 (plan_beam / plan_footing / plan_slab) ยังไม่เทรน ยังไม่วัด — ตอนนี้ Pass 4 ใช้ element จากไฟล์เฉลยแทน ไม่ได้หาเอง

(สองบรรทัดบนเป็นสรุปของฉันจากบทสนทนา ไม่ใช่คำตัดสินที่มะขามเคยยืนยันเป็นลายลักษณ์อักษร ต่างจาก README ใน pass_gridline)

## อินพุตสองอย่างของ Pass 4 ที่ยังมาจากเฉลย ไม่ใช่ผลของ pass ก่อนหน้า (เช็คกับโค้ด 21 พ.ย.)
- **รายการ element + grid_ref:** จากไฟล์เฉลย (`element_files()`)
- **grid master (ชื่อเส้น + เมตร + ชนิด named/dummy):** จากไฟล์เฉลย `*gridline*.json` (`load_master()`) ไม่ใช่ `grid_master.json` ที่ Pass 3 สร้าง — Pass 3 → Pass 4 ยังไม่ได้ต่อสาย
- ที่เป็น logic/OCR จริง: เส้นกริดและตำแหน่งบนหน้า (`gridlab_probe.detect(ocr=True)`) · ฟิต · ล็อก · ตรวจกับของที่วาด

## Pass 4 SP ทำอะไรจริง (`tools/pass4_sp.py` · ยังไม่ commit · ไม่เรียกโมเดล)
1. **ตารางกริดสำหรับ "Analyze SP":** ต่อแปลนฟิตเส้นตรง `pt = a·เมตร + b` ต่อแกน (pt จากเส้นกริดที่ grid lab หาได้บนหน้า, เมตรจาก grid master ของเฉลย) (เส้นใดคลาดเกิน 3 pt = ทิ้งแปลนนั้น) ได้ตาราง ชื่อ · เมตร · pt · พิกเซลที่ 200 dpi
2. **Pixel lock:** `grid_ref` ของ element -> ตำแหน่งบนภาพ · คาน = เส้นจากจุดต้นถึงจุดปลาย · เสา/ฐานราก = จุด · แผงพื้น `A-B x 1-2` = กรอบ · แยกชื่อไม่ได้หรือกำกวม = ไม่ล็อก ไม่เดา
3. **ตรวจกับของที่วาด (เฉพาะหน้าเวกเตอร์):**
   - จุด: มีกรอบของสิ่งที่วาด (สี่เหลี่ยมที่วาดจริง + กรอบล้อมทุก path) ขนาดพอดีเสา/ฐานราก (ด้านสั้น ≥ 2.5 pt, ด้านยาว ≤ 2.5 ม.) ครอบจุด · ฐานรากอนุโลมเส้นทึบสี่ด้านแยกกันล้อมจุด
   - คาน: มีเส้นทึบขนานแกน ห่าง 1 pt ถึง 0.4 ม. ครอบคลุม ≥ 60% ของจุดตัวอย่าง 9 จุด (ตัดเส้นประกริด)
   - ตัวควบคุม: จุดตัดกริดที่ไม่มี element และช่วงกริดที่ไม่มีคาน

## ผลวัดวันนี้ (ทุกเล่มที่ 6 ที่มี grid master, 2 หน้าแปลนต่อเล่ม, 53 หน้า — จากบันทึกของ session ที่สร้างไฟล์นี้)

## ต้องรู้เวลาอ้างตัวเลข
- "เจอของที่วาด" แปลว่าตรงนั้นมีของชนิดที่ถูกวาดอยู่ ไม่ได้แปลว่าเป็น mark ที่ถูก — สลับ mark สองตัวที่ตำแหน่งถูกต้อง จับไม่ได้
- ตัวควบคุม 17% เพราะจุดตัดคานและเสาอยู่บนหลายจุดตัดกริด · กรอบนับจากเส้นทุกเส้น สิ่งเล็กๆ อื่นก็อาจนับเป็นเจอ จึงต้องอ่านคู่กับตัวควบคุมเสมอ
- ตัวเลขวัดแค่ "ตารางกริดที่ส่งให้ + การล็อกพิกเซล" ไม่ได้วัดความสามารถอ่านแบบของโมเดล
