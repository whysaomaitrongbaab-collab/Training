## apply_arm() — ตัวสลับแขนทดลอง (อยู่ใน infer_house_t03.py ไม่ใช่ไฟล์แยก)

ไม่มีไฟล์ชื่อ apply_arm.py — มันคือ**ฟังก์ชัน** `apply_arm()` ใน
`tune_ai/t03/data_before_tune/infer_house_t03.py` (ตัวรันวัดผลโมเดล)

**มีไว้ทำไม:** การทดลอง 2 แขนต้องยิง "หน้าเดียวกัน prompt เดียวกัน โมเดลเดียวกัน"
ต่างกันแค่มี/ไม่มีโพย — ถ้าให้คนไปแก้ prompt เองทีละรอบ เดี๋ยวก็แก้พลาดแล้วผลเทียบกันไม่ได้
apply_arm() คือคนกลางที่รับ content เดิม แล้ว "เติมของ" ตามแขนที่เลือกด้วย flag `--arm`
คนรันไม่ต้องแตะ prompt เลย

**ทำงานยังไง (หลังตัด 2.4b แล้ว เหลือเรียบมาก):**
1. แขน "2" → คืนของเดิมเป๊ะ ไม่แตะอะไร (ตัวคุม)
2. แขน "2.4a" → ไปหาไฟล์โพย `<ชื่อรูป>_hint.txt` ในโฟลเดอร์ sidecar (`--cv-dir`)
   เจอ → แปะข้อความโพยต่อท้าย prompt แล้วบันทึก `hint_used: true`
3. **หาไม่เจอ → คืนของเดิม + `hint_used: false`** — แถวนั้นกลายเป็นแขน 2 โดยพฤตินัย
   ไม่ error ไม่เดา ไม่สร้างโพยเปล่า (สำคัญ: บ้านที่คลัง template ยังไม่รู้จัก CV จะนับได้ 0
   ก็จะไม่มีโพยเอง — ระบบไม่พังแค่บันทึกไว้ให้เห็น)

**อ่านผลยังไง:** ใน results ทุกแถวมี `hint_used` — แขน 2.4a ของหน้าที่มี sidecar
ต้องเป็น true ถ้า false แปลว่า path `--cv-dir` ผิด หยุดเช็คก่อนยิงต่อ (เปลือง GPU ฟรี)

## ศัพท์ที่โผล่บ่อย

- **sidecar** = ไฟล์ผลพลอยได้ที่วางข้างรูป (`_cv.json` / `_hint.txt` / `_marked.png`)
- **hint / โพย** = ข้อความบอกโมเดลว่า CV เห็นอะไรกี่จุด — เป็นคำใบ้ ไม่ใช่คำตอบ
  (กฎ 4 ข้อกันโมเดลเชื่อโพยเกินไป)
- **arm / แขน** = เงื่อนไขการทดลอง 1 แบบ — เทียบกันเพื่อตอบ "โพยช่วยจริงไหม"
- **GT (ground truth)** = เฉลยที่คนตรวจแล้ว ใช้ให้คะแนนโมเดล
- **recall_printed** = เปอร์เซ็นต์มาร์คที่พิมพ์บนแบบจริงที่โมเดลอ่านเจอ — ตัวชี้วัดหลัก
- **template / คลัง** = รูปไอคอนตัวอย่าง (tools/templates/) ที่ CV เอาไปถูหาทั้งภาพ
