The honest answer, recorded here because it's a recurring caveat worth having written down once properly rather than repeated informally each time: `npm test` runs the repo's Node-based unit test suite (~1986 cases across ~12 files under `tests/`) — each case feeds small, hand-constructed sample data into a pure function (e.g. `buildStructureModel()`, `computeBOQ()`) and asserts the output matches a value that was hand-calculated before the test was written.
