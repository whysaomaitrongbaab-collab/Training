## [Mail (Mel) & AI pair session] Added Mobile Resource Hub tracking page with 2-tab navigation to `contistant-site-checklist.html`, implemented 100% field-safe projection (zero cost/rate leakage), and fixed mobile viewport overflow blowout

**Context:** Continuation of the mobile field app work (`contistant-site-checklist.html`). Following Phase 1's checklist completion, Mail requested adding a mobile-friendly view of the Resource Hub (which Ton has been developing on desktop) so that field supervisors can monitor on-site manpower, materials, and machinery directly from their phones. Two strict constraints were set by Mail: (1) **Zero risk to desktop code** — `contistant.html` and core desktop modules must not be touched or broken in any way; (2) **Clean UX/UI** — a 2-page structure with bottom navigation (`✅ เช็คลิสต์หน้างาน` and `🏗️ Resource Hub`), tailored specifically for mobile phone screens.

**Work done:**

1. **Designed and implemented pure, field-safe Resource Hub projection (`Constistant/js/shared/field-resource-view.js`):**
   - Built `buildFieldResourceView(project, boq, scheduleTasks, resourceAllocations, materialOrders)` as a read-only projection following the exact architectural pattern established by `field-view.js`.
   - **Enforced strict Field-Safe Whitelist:** Under Thai construction contracting practices, site foremen and subcontractors must never see project unit prices, profit margins, subcontractor billing rates, or contract lump sums. The projection filters out all financial fields (`unit_price`, `total_price`, `cost`, `budget`, `wage`, `daily_rate`) and produces only operational and physical metrics:
     - **Manpower Tracking:** Aggregates crew demand by date and trade (e.g. `ช่างไม้แบบ`, `ช่างเหล็ก`, `ช่างปูน`) directly from active CPM schedule tasks for the selected date. Calculates planned workers, confirmed headcounts, crew shortages, and active trade badges.
     - **Materials Tracking:** Maps physical material orders and delivery statuses against schedule task start dates. Computes required dates, lead times, delivery progress (percent fulfilled / remaining), and flags urgent orders (`วิกฤต - สั่งด่วน` when `daysUntilNeeded <= leadTimeDays`).
     - **Machinery / Equipment Tracking:** Aggregates heavy equipment allocations (e.g. `รถขุด Backhoe`, `รถเครน Mobile Crane`, `รถโม่คอนกรีต Ready-Mix Truck`) by active date windows, tracking booking status (`ยืนยันแล้ว`, `รอจัดสรร`, `เสร็จสิ้น`) and operational requirements without displaying machine rental rates.
   - Supports seamless fallback to standard trade heuristics and baseline BOM when explicit allocation records are not yet generated, guaranteeing the mobile UI always displays actionable operational data.

2. **Added 2-Tab Navigation and Resource Hub UI to `Constistant/contistant-site-checklist.html`:**
   - Introduced a fixed mobile bottom navigation bar (`.fld-bottom-nav`) with two distinct tabs:
     - Tab 1: `✅ เช็คลิสต์หน้างาน` (Earthwork, Pre-pour checklist, Inspection notes)
     - Tab 2: `🏗️ Resource Hub` (Manpower crew demand, Material deliveries, Equipment status)

     - Manpower section: Crew summary KPIs (total planned, confirmed, shortages, active trades), trade breakdown cards with progress bars and status badges (`พร้อมทำงาน`, `ขาดคน`).
     - Materials section: Delivery summary KPIs, itemized cards with remaining physical quantities, status chips (`ส่งแล้ว`, `กำลังส่ง`, `ยังไม่สั่ง`), and urgent delivery alert banners.
     - Machinery section: Equipment cards with operator assignment tags, operational date ranges, and booking confirmation status.

   - Added tab switching state management (`activeTab: 'checklist' | 'resources'`) with persistent bottom-nav active states and smooth panel transitions.
   - Connected project change events (`PROJECT_EVENT`) and storage events so that switching active projects immediately refreshes both the checklist and resource projections.
   - Added dedicated rendering functions: `fld_renderResourceView()`, `fld_renderCrewSection()`, `fld_renderMaterialsSection()`, and `fld_renderMachinerySection()`.
