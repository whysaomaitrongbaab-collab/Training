## xgrammar เปิดทุก pass (มะขามสั่ง "ใส่ x gramma ทุก pass ตามความเหมาะสม")

- ตรวจก่อนตัดสิน: grammar ที่ใช้คือ `compile_builtin_json_grammar()` = บังคับแค่ "เป็น JSON ถูกไวยากรณ์" ไม่ใช่ schema เฉพาะรูป → ถูกความหมายกับทุก subtask (grid{}/notes{}/elements[]/categories[] ล้วนเป็น JSON object เดียว) "ความเหมาะสม" จึง = เปิดหมดเป็นค่าปริยาย ไม่มี subtask ที่ต้องยกเว้น
- infer_house_t03.py: เงื่อนไข plan_beam-only → `use_g = grammar` ทุก subtask · `--grammar-all` เป็น no-op (คงไว้กันสคริปต์เก่าพัง) · `--no-grammar` ยังปิดได้ไว้ทำ A/B · กติกาถาวร plan_beam เดิม (2026-08-24, 96.8% vs 57.9%) ยังจริงโดยอัตโนมัติเพราะเป็น subset · py_compile ผ่าน
- จารึกนโยบายไว้ที่ runner อนาคตด้วย: pass3_takeoff/prompt.md (ยิ่งจำเป็น — merge_guard ทำงานได้ต่อเมื่อ parse JSON ได้ก่อน ไม่งั้น stub ทั้งหน้า) + pass0/README.md (JSON พัง = หน้าหลุด route ทั้งใบ) — runner ใหม่ต้องเกิดมาพร้อม xgrammar เลย
- RUNBOOK + WORKFLOW เตือนเรื่องอ่านเลขเทียบรอบเก่า: subtask อื่นที่ไม่ใช่ plan_beam รอบเก่าไม่มี grammar — JSON-valid ที่กระโดดขึ้นส่วนหนึ่งมาจาก grammar ไม่ใช่โมเดลเก่งขึ้นอย่างเดียว
